# Materi Kuliah — Prodi Informatika UAI

**Penyusun Materi:** Tri Aji Nugroho, S.T., M.T.

---

Repository ini berisi **materi kuliah lengkap** untuk sepuluh mata kuliah di Program Studi Informatika, Fakultas Sains dan Teknologi, Universitas Al Azhar Indonesia — **delapan** mata kuliah aktif pada Kurikulum Informatika 2025 Revisi 2026 dan **dua** mata kuliah arsip dari kurikulum sebelumnya. Seluruh materi dirancang dengan pendekatan **Outcome-Based Education (OBE)** sesuai SN-Dikti/KKNI, dengan integrasi **AI-Augmented Learning** sebagai pendekatan modern dalam proses belajar-mengajar.

Materi disusun **per semester kurikulum** (`mata-kuliah/semester-1/` … `semester-8/`). Semester ganjil kurikulum (1, 3, 5, 7) dilaksanakan pada **Semester Ganjil** tahun akademik; semester genap kurikulum (2, 4, 6, 8) pada **Semester Genap**. Setiap folder semester memiliki `README.md` berisi peta seluruh mata kuliah semester itu menurut [registri kurikulum](mata-kuliah/00-kurikulum-if-2025-revisi-2026/11-susunan-mata-kuliah-dan-dosen.md), termasuk yang belum memiliki materi di repositori ini.

Empat mata kuliah terbaru — Probabilitas dan Statistik, Dasar Kecerdasan Artifisial dan Pembelajaran Mesin, Teknopreneur, dan Metodologi Penelitian — disusun **langsung dari [Kurikulum Informatika 2025 Revisi 2026](mata-kuliah/00-kurikulum-if-2025-revisi-2026/)**, dengan Sub-CPMK, indikator, kriteria, dan bobot penilaian yang diturunkan verbatim dari registri.
