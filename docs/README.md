# UAI Interactive Learning Hub — Probabilitas dan Statistika

Sumber: folder Google Drive **WEB INTERAKTIF** (16 berkas HTML, diambil 16 Oktober 2026). Sumber asli tidak dimodifikasi.

## Hosting

Repository GitHub: `triajinugroho/research-ai-agentic`

Untuk menerbitkan sebagai GitHub Pages: repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /docs → Save**.

Alamat yang diharapkan setelah Pages aktif: https://triajinugroho.github.io/research-ai-agentic/

## Struktur

- `docs/index.html`: portal 16 modul, responsif, pencarian dan filter.
- `docs/probstat/bagian-01.html` sampai `bagian-16.html`: modul sumber, hanya membuang wrapper HTML ganda hasil ekspor Drive.
- `docs/probstat/index.html`: pintasan kembali ke katalog.

## Pengujian yang dibutuhkan

1. Pastikan Pages sukses terbit dan semua 16 tautan dapat dibuka.
2. Uji kuis, tombol, tab, simulasi, dan tampilan mobile pada sampel modul di perangkat nyata.
3. Uji storage browser; kemajuan belajar lokal bukan nilai Moodle.
4. Tinjau konsistensi substansi dengan RPS dan lisensi publikasi sebelum distribusi.

Catatan: GitHub Pages bersifat publik dan tidak menyediakan autentikasi mahasiswa atau sinkronisasi nilai tanpa sistem tambahan.
