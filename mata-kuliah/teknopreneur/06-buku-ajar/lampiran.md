## Lampiran A — Templat Siap Pakai

### A.1 Kesepakatan Tim

```markdown
# Kesepakatan Tim — [nama tim]
Disusun: [tanggal]   ·   Anggota: [4 nama]

## Peran
| Nama | Peran | Bertanggung jawab atas |
|------|-------|------------------------|
|      | Koordinator | Jadwal, tenggat, dokumentasi |
|      | Penanggung jawab bukti | Kelengkapan catatan wawancara |
|      | Penanggung jawab angka | Setiap angka punya sumber |
|      | Penanggung jawab komunikasi | Deck, laporan, presentasi |

## Pertemuan
Waktu tetap : [hari, jam]        Durasi: [menit]
Dianggap hadir bila: [ketentuan]
Bila berhalangan: [ketentuan]

## Keputusan
Cara memutuskan: [mufakat / suara terbanyak]
Bila 2 lawan 2 : [ketentuan]
Dicatat di     : jurnal-keputusan.md

## Kontribusi
Diukur dengan  : [catatan kontribusi mingguan]
Bila timpang   : (1) dibicarakan di rapat (2) ditulis di jurnal
                 (3) dibawa ke dosen

## Pemakaian AI
Boleh untuk    : [daftar]
Tidak boleh    : mengarang wawancara, mengisi angka, menulis pitch
Dicatat di     : log-ai.md, setiap kali

## Perselisihan
Langkah 1: bicara berdua   Langkah 2: rapat tim
Langkah 3: dosen pengampu

Ditandatangani: [4 nama, tanggal]
```

## Lampiran B — Daftar Periksa

### B.1 Sebelum Berangkat Wawancara

| # | Butir | ☐ |
|---|-------|---|
| 1 | Panduan pertanyaan sudah diperiksa, tidak ada yang memimpin | ☐ |
| 2 | Pembuka memuat: siapa, untuk apa, bukan menjual, berapa lama | ☐ |
| 3 | Tidak ada satu pun pertanyaan yang menyebut gagasan solusi | ☐ |
| 4 | Pembagian peran: siapa bertanya, siapa mencatat | ☐ |
| 5 | Alat catat siap; izin rekaman akan diminta lisan | ☐ |
| 6 | Pertanyaan penutup "siapa lagi yang sebaiknya kami temui" | ☐ |

### B.2 Audit Etika — `Gharar`

| # | Pertanyaan | Ya/Tidak | Perbaikan |
|---|------------|----------|-----------|
| 1 | Harga total jelas sebelum pengguna menyetujui? | | |
| 2 | Syarat berlangganan dinyatakan di muka? | | |
| 3 | Pengguna tahu sampai kapan layanan ini ada? | | |
| 4 | Pengguna tahu data apa yang disimpan? | | |
| 5 | Cara berhenti jelas dan satu langkah? | | |
| 6 | Pengguna tahu bahwa angka kami perkiraan? | | |

### B.3 Audit Etika — `Tadlis`

| # | Pertanyaan | Ya/Tidak | Perbaikan |
|---|------------|----------|-----------|
| 1 | Ada bagian demo yang belum berfungsi tanpa keterangan? | | |
| 2 | Ada bagian manual yang tampak otomatis tanpa keterangan? | | |
| 3 | Ada kesaksian pengguna yang tidak nyata? | | |
| 4 | Ada angka promosi yang tak dapat dibuktikan? | | |
| 5 | Ada keterbatasan penting yang tidak disebutkan? | | |
| 6 | Ada ulasan yang dibuat tim sendiri tanpa keterangan? | | |

### B.4 Audit Etika — `Ghabn`

| # | Pertanyaan | Ya/Tidak | Perbaikan |
|---|------------|----------|-----------|
| 1 | Harga wajar dibanding nilai yang diberikan? | | |
| 2 | Pengguna dapat pindah membawa datanya? | | |
| 3 | Harga dinaikkan setelah pengguna sulit pindah? | | |
| 4 | Kita memanfaatkan ketidaktahuan pengguna? | | |
| 5 | Pengguna yang tidak paham teknologi diperlakukan sama? | | |

### B.5 Sebelum Demo Day

| # | Butir | ☐ |
|---|-------|---|
| 1 | Deck 10 halaman, setiap angka bersumber | ☐ |
| 2 | Latihan berwaktu ≥5 kali | ☐ |
| 3 | Latihan sekali tanpa slide | ☐ |
| 4 | 15 pertanyaan sulit disiapkan jawabannya | ☐ |
| 5 | Demo diuji di perangkat yang akan dipakai | ☐ |
| 6 | Data contoh diberi label di layar | ☐ |
| 7 | Bagian manual dinyatakan | ☐ |
| 8 | Berkas bukti lengkap dan dapat ditunjukkan | ☐ |
| 9 | Log AI terisi sampai hari terakhir | ☐ |
| 10 | Cadangan bila internet mati | ☐ |

### B.6 Kata dan Klaim yang Dilarang

| Kata / klaim | Ganti dengan |
|--------------|--------------|
| "Solusi terintegrasi" | Sebutkan apa yang dilakukannya |
| "Berbasis AI" (sebagai manfaat) | Sebutkan hasil yang dirasakan pengguna |
| "Platform" | Sebutkan bentuk nyatanya |
| "Memberdayakan" | Sebutkan yang berubah |
| "Mudah dan cepat" | Sebutkan angkanya |
| "Hingga __%" | Angka yang benar-benar diukur |
| "Dipercaya ratusan…" | Jumlah sebenarnya |
| "Tidak ada kompetitor" | Termasuk "tidak melakukan apa-apa" |
| "Satu-satunya di Indonesia" | "Kami belum menemukan layanan sejenis untuk segmen ini" |

## Lampiran C — Sumber Data Indonesia yang Dapat Ditelusuri

### C.1 Lembaga dan Terbitannya

| Lembaga | Terbitan yang relevan | Keterangan |
|---------|----------------------|------------|
| **Badan Pusat Statistik (BPS)** | *Statistik Usaha Mikro dan Kecil*; *Survei Sosial Ekonomi Nasional (Susenas)*; *Statistik Telekomunikasi Indonesia* | Definisi UMKM mengikuti kriteria omzet/aset — periksa kesesuaiannya |
| **Kementerian Koperasi dan UKM** | *Data UMKM*; laporan kinerja tahunan | Jumlah pelaku usaha per sektor |
| **Kementerian Investasi/BKPM** | *Data Perizinan Berusaha (OSS)* | Jumlah NIB terbit per wilayah dan sektor |
| **Bank Indonesia** | *Survei Penjualan Eceran*; *Laporan Sistem Pembayaran* | Kecenderungan konsumsi dan pembayaran |
| **Otoritas Jasa Keuangan** | *Survei Nasional Literasi dan Inklusi Keuangan* | Akses keuangan per kelompok |
| **Kominfo** | *Survei Penggunaan TIK*; panduan pelindungan data | Kepemilikan perangkat dan akses internet |
| **Pemerintah daerah** | Data dinas koperasi/perdagangan kota atau kabupaten | Paling relevan untuk segmen lokal |

### C.2 Ketentuan Pemakaian Angka

| Ketentuan | Penjelasan |
|-----------|------------|
| 1 | Setiap angka mencantumkan: lembaga, nama terbitan, tahun, nomor tabel |
| 2 | Definisi dalam terbitan diperiksa kesesuaiannya dengan maksud tim |
| 3 | Angka yang tidak dapat ditelusuri ke terbitan aslinya **dihapus** |
| 4 | Angka hasil hitungan tim ditandai sebagai hitungan tim, dengan metodenya |
| 5 | Angka dari asisten AI **tidak sah** kecuali terbitannya ditemukan dan dibuka |

### C.3 Pencacahan Sendiri

Ketika data resmi tidak tersedia pada tingkat yang diperlukan — dan untuk segmen sempit hal ini sering terjadi — pencacahan sendiri adalah sumber yang sah dan sering lebih kuat.

```markdown
## Metode Pencacahan — [tanggal]

Wilayah    : [kecamatan/ruas jalan]
Kriteria   : [apa yang dihitung; apa yang tidak]
Cara       : [berjalan menyusuri; mencatat; jam berapa]
Pencacah   : [nama, berapa orang]
Hasil      : __ unit pada __ ruas jalan
Ekstrapolasi: [metode, dengan asumsinya dinyatakan]
Keterbatasan: [yang mungkin terlewat]
```

Bagian "Keterbatasan" wajib diisi. Pencacahan siang hari melewatkan usaha yang buka malam; pencacahan di jalan besar melewatkan yang ada di gang.

## Lampiran D — Perkakas Tanpa Biaya

| Keperluan | Pilihan | Catatan |
|-----------|---------|---------|
| Catatan bersama | Google Docs, Notion | Riwayat perubahan terlihat |
| Tabel dan hitungan | Google Sheets | Cukup untuk seluruh perhitungan buku ini |
| Papan sintesis | Miro, FigJam, atau **kertas tempel di dinding** | Kertas sering lebih baik untuk sintesis tim |
| Prototipe kertas | Kertas dan pena | Tidak tergantikan untuk uji alur |
| Prototipe layar | Figma | Gratis untuk pendidikan |
| Halaman penjelasan | Carrd, Google Sites | Cukup untuk uji tawaran |
| Formulir | Google Forms | Untuk pendaftaran, bukan untuk wawancara |
| Pesan ke pengguna | WhatsApp | Saluran yang benar-benar dipakai segmen UMKM |
| Penjadwalan pesan | Fitur bawaan atau manual | Untuk MVP, manual sudah cukup |
| Penyimpanan berkas | Google Drive | Atur izin akses per anggota |
| Presentasi | Google Slides, Canva | Sediakan cadangan PDF |

> Tidak satu pun perkakas dalam daftar ini menuntut biaya atau kemampuan pemrograman. Mata kuliah ini tidak menilai penguasaan perkakas.
