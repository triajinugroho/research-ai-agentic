| 1 | Setiap sitasi wajib **terverifikasi**: DOI atau tautan permanen yang dapat dibuka |

| 3 | Setiap angka wajib mencantumkan lembaga, terbitan, tahun, dan nomor tabel |

### B.3 Memeriksa Mutu Jurnal

| Langkah | Cara |
|---------|------|
| 1 | Cari nama jurnal pada **DOAJ** |
| 2 | Periksa indeksasi: Scopus, Web of Science, atau SINTA |
| 3 | Buka beberapa artikel terbitannya; nilai mutunya sendiri |
| 4 | Periksa dewan editor: apakah orangnya nyata dan bidangnya sesuai |
| 5 | Periksa tenggang waktu antara pengiriman dan penerimaan |

| Tanda penerbit predator | Penjelasan |
|-------------------------|------------|
| Ajakan lewat surel yang memuji berlebihan | Terbitan bermutu tidak memburu naskah |
| Menjanjikan terbit dalam hitungan hari | Telaah sejawat menuntut waktu |
| Biaya dinyatakan setelah naskah diterima | Ketidakjelasan yang disengaja |
| Cakupan sangat luas | "Sains, teknologi, seni, dan humaniora" |
| Dewan editor tidak dapat diverifikasi | Nama dicantumkan tanpa izin |

## C. Sumber Data Indonesia

### C.1 Lembaga Resmi

| Lembaga | Terbitan/basis data | Kegunaan |
|---------|--------------------|----------|
| **Badan Pusat Statistik (BPS)** | Susenas, Sakernas, Statistik Telekomunikasi, Statistik UMK | Data populasi, sosial ekonomi, akses TIK |
| **Kementerian Kominfo** | Survei Penggunaan TIK; panduan pelindungan data | Kepemilikan perangkat, akses internet |
| **Kementerian Koperasi dan UKM** | Data UMKM | Jumlah dan sebaran pelaku usaha |
| **Kementerian Investasi/BKPM** | Data OSS | Perizinan berusaha per wilayah |
| **Kemendikbudristek** | PDDIKTI, Dapodik | Data pendidikan |
| **Kementerian Kesehatan** | Riskesdas, SIRS | Data kesehatan (perhatikan ketentuan akses) |
| **Bank Indonesia** | Survei Penjualan Eceran, Laporan Sistem Pembayaran | Kecenderungan ekonomi dan pembayaran |
| **Otoritas Jasa Keuangan** | SNLIK | Literasi dan inklusi keuangan |
| **Satu Data Indonesia** | Portal data terpadu | Titik masuk lintas kementerian |
| **Pemerintah daerah** | Portal data kota/kabupaten | Paling relevan untuk penelitian lokal |

### C.2 Memeriksa Kesesuaian Definisi

Angka dari lembaga resmi sering memakai definisi yang berbeda dari yang
dimaksud peneliti.

| Contoh | Perbedaannya |
|--------|--------------|
| "UMKM" menurut BPS | Berdasarkan kriteria omzet dan aset tertentu |
| "Pengguna internet" | Definisi berbeda antar-survei (pernah memakai vs memakai rutin) |
| "Usaha mikro" | Batasan berubah setelah PP tertentu |

Sebelum memakai sebuah angka: **buka definisinya dalam terbitan aslinya** dan
periksa apakah sesuai dengan populasi yang Anda maksud. Bila berbeda, angka
itu tidak dapat dipakai begitu saja meskipun terbitannya asli.

### C.3 Pencacahan Sendiri

Untuk segmen yang tidak tercakup data resmi — keadaan lazim pada penelitian
bersegmen sempit — pencacahan sendiri adalah sumber yang sah.

```markdown
## Metode Pencacahan — [tanggal]

Wilayah     : [batas persis]
Kriteria    : [apa yang dihitung; apa yang tidak]
Cara        : [prosedur; jam berapa; berapa pencacah]
Hasil       : __ unit pada __ [satuan wilayah]
Ekstrapolasi: [metode, dengan asumsi dinyatakan]
Keterbatasan: [yang mungkin terlewat]
```

Bagian "Keterbatasan" wajib diisi. Pencacahan siang hari melewatkan usaha
yang buka malam; pencacahan di jalan besar melewatkan yang ada di gang.

## D. Basis Data untuk Penelitian Berbasis Artefak

| Sumber | Isi | Catatan |
|--------|-----|---------|
| **Zenodo** | Data dan kode penelitian, dengan DOI | Juga tempat menyimpan paket reproduksi |
| **figshare** | Data, gambar, naskah | DOI tersedia |
| **OSF** (Open Science Framework) | Praregistrasi, data, protokol | Berguna untuk menandai rencana analisis |
| **Kaggle** | Kumpulan data | **Periksa asal dan lisensinya** |
| **UCI ML Repository** | Kumpulan data klasik | Banyak yang sudah sangat tua |
| **Hugging Face Datasets** | Data untuk NLP dan ML | Periksa lisensi dan asal data |
| **PapersWithCode** | Makalah beserta implementasinya | Berguna mencari *baseline* |

> Untuk data dari repositori terbuka, **lisensi dan asal data wajib
> diperiksa**. Sebagian kumpulan data populer memiliki pembatasan pemakaian
> atau persoalan etik yang tidak terlihat dari namanya.

## E. Perkakas

| Keperluan | Pilihan | Catatan |
|-----------|---------|---------|
| Pengelola pustaka | **Zotero** | Gratis; ekstensi peramban; sinkronisasi |
| | Mendeley, JabRef | Alternatif |
| Penandaan kualitatif | Taguette | Gratis, terbuka |
| | Spreadsheet | Memadai untuk skala Tugas Akhir |
| Analisis kuantitatif | R, Python (pandas, scipy, statsmodels) | Gratis |
| | JASP, jamovi | Antarmuka grafis, gratis |
| | SPSS | Bila tersedia lisensi kampus |
| Penulisan | LaTeX (Overleaf), Word, Markdown | Sesuai ketentuan program studi |
| Penyimpanan paket reproduksi | Zenodo, OSF, repositori kampus | Zenodo memberi DOI |
| Pemeriksaan kemiripan | Sesuai ketentuan fakultas | |

> Zotero sangat dianjurkan sejak Minggu 1. Pengelola pustaka yang dipakai
> sejak awal menghemat berjam-jam pada Minggu 15, dan memudahkan verifikasi
> DOI karena metadata terekam saat sumber ditambahkan.

## F. Pedoman Etik dan Regulasi

| Sumber | Isi |
|--------|-----|
| **UU No. 27 Tahun 2022** | Pelindungan Data Pribadi |
| **UU ITE** dan perubahannya | Informasi dan transaksi elektronik |
| **Pedoman etik penelitian perguruan tinggi** | Ketentuan kampus; kaji etik bila diperlukan |
| **ACM Code of Ethics** | Etika profesi komputasi |
| **COPE** | Etika penerbitan, termasuk posisi tentang perkakas AI |
| **Panduan Etika Kecerdasan Artifisial Indonesia (Kominfo)** | Konteks nasional |

Penelitian yang melibatkan manusia sebagai subjek mengikuti ketentuan kaji
etik yang berlaku di fakultas. Untuk penelitian yang hanya mewawancarai
pengguna sistem tanpa intervensi, biasanya cukup persetujuan tertulis — namun
ketentuan kampus yang menentukan.
