## Lampiran A — Templat Siap Pakai

### A.1 Analisis Kesenjangan

```markdown
## Fenomena
[Satu paragraf: apa yang teramati]

## Bukti bahwa fenomena ini nyata
| Bukti | Sumber | Jenis |
|-------|--------|-------|
| | | data resmi / laporan / pengamatan sendiri |

## Apa yang sudah diketahui
| # | Sitasi | DOI | Yang ditunjukkan | Konteks/populasi |
|---|--------|-----|------------------|------------------|
| 1 | | | | |

## Jenis kesenjangan
[bukti / pengetahuan / populasi / metodologis / praktik-teori / pertentangan]

## Pernyataan kesenjangan
Penelitian terdahulu telah menunjukkan [APA] pada [KONTEKS] [sitasi].
Namun [APA YANG BELUM], khususnya pada [KONTEKS BERBEDA].
Ketidaktahuan ini penting karena [AKIBAT PRAKTISNYA].

## Apa yang akan membantah kesenjangan ini
[Keadaan yang, bila ditemukan pada penelusuran, akan mengubahnya]
```

### A.2 Protokol Penelusuran

```markdown
## Protokol Penelusuran Literatur — [tanggal]

### Konsep dan sinonim
| Konsep | Istilah utama | Sinonim |
|--------|---------------|---------|
| A | | |

### Rumus pencarian
| Basis data | Rumus persis | Tanggal | Hasil |
|------------|--------------|---------|-------|

### Kriteria inklusi
- Terbit [tahun]–2026
- Bahasa: Indonesia atau Inggris
- Jenis: [sebutkan]
- Membahas [konsep A] pada [konteks B]

### Kriteria eksklusi
- [daftar]

### Diagram alir
Identifikasi  : ___   (duplikat dibuang: ___)
Penyaringan   : diperiksa ___, dibuang ___ (alasan tersering: ___)
Kelayakan     : diperiksa ___, dibuang ___ (alasan: ___)
Disertakan    : ___   (dibaca penuh: ___)
```

### A.3 Matriks Sintesis

```markdown
| # | Sitasi | DOI | Masalah | Metode | Data/subjek | Temuan | Keterbatasan (diakui penulis) | Relevansi |
|---|--------|-----|---------|--------|-------------|--------|-------------------------------|-----------|
| 1 | | | | | | | | |

### Tema
| Tema | Baris | Disepakati | Bertentangan | Belum disentuh |
|------|-------|------------|--------------|----------------|
```

### A.4 Tabel Keselarasan

```markdown
| Masalah | RQ | Bentuk RQ | Tujuan | Metode | Kontribusi |
|---------|----|-----------|--------|--------|------------|
| | RQ1 | deskriptif/hubungan/penjelasan | | | |
| | RQ2 | | | | |

### Uji kelayakan
| RQ | Data yang diperlukan | Dari siapa/mana | Sudah diakses? | Waktu |
|----|---------------------|-----------------|----------------|-------|
```

### A.5 Catatan Wawancara

```markdown
## Wawancara N__ — [tanggal]

| Aspek | Isi |
|-------|-----|
| Narasumber | [inisial] — [peran], [lama bekerja] |
| Durasi | __ menit |
| Cara | tatap muka / panggilan |
| Persetujuan | diberikan [lisan/tertulis] pada [waktu] |
| Kuadran stakeholder | |

### Kutipan Verbatim
1. "…"
2. "…"

### Pengamatan
-

### Yang Mengejutkan
[WAJIB DIISI]

### Kendala yang teridentifikasi
- K-__ :
```

### A.6 Kendala → Kriteria

```markdown
| Kode | Kendala | Sumber | Kriteria kebutuhan | Cara mengukur |
|------|---------|--------|--------------------|---------------|
| K-01 | | N1, N3 | | |
```

### A.7 Kerangka Konseptual

```markdown
### Konstruk
| Konstruk | Definisi konseptual | Definisi operasional | Sumber |
|----------|--------------------|-----------------------|--------|

### Hubungan
| Hubungan | Arah | Sumber | Status |
|----------|------|--------|--------|
| A → B | + | [sitasi] | bersumber / usulan peneliti |

### Variabel kendali
| Variabel | Alasan dikendalikan |

### Variabel yang TIDAK dimasukkan
| Variabel | Mengapa tampak relevan | Mengapa tidak dimasukkan |
```

### A.8 Pemilihan Rancangan

```markdown

### Rencana cadangan
Skenario A : [keadaan] → [yang berubah] → tenggat memutuskan: Minggu __
Skenario B : ...
```

### A.10 Rencana Analisis (Bertanggal)

```markdown
## Rencana Analisis Data — ditetapkan [tanggal]
(Tanggal ini harus MENDAHULUI pengumpulan data)

### Variabel
| Variabel | Dari butir | Skala | Rentang |

### Analisis per RQ
| RQ | Data | Analisis | Keluaran |

### Asumsi
| Analisis | Asumsi | Cara memeriksa | Bila tidak terpenuhi |

### Kriteria penolakan
Dugaan              :
Didukung bila       :
Tidak didukung bila :
Tidak dapat disimpulkan bila:
Yang dilaporkan dalam ketiga keadaan: seluruhnya.
```

### A.11 Kriteria Evaluasi Artefak

```markdown
| Kriteria | Tertelusur ke | Cara mengukur | Ambang | Sumber ambang |
|----------|---------------|---------------|--------|---------------|
| | K-__ (N_, N_) | | | kendala/keadaan sekarang/pustaka/standar |

### Pembanding
| Pembanding | Apa yang dibandingkan | Cara mengukur | Penyetelan |

### Rencana pelaporan kegagalan
[Untuk setiap kriteria: apa yang dilaporkan bila ambang tidak tercapai,
 dan pengetahuan apa yang tetap dihasilkan]
```

### A.12 Deklarasi AI

```markdown
## Deklarasi Pemakaian AI

| Tahap | Perkakas | Untuk apa | Cara verifikasi |
|-------|----------|-----------|-----------------|
| | | | |

**Tidak memakai bantuan AI:** [sebutkan bagian secara spesifik]

Saya bertanggung jawab penuh atas seluruh isi naskah ini.

[nama], [NIM], [tanggal]
```

### A.13 Lembar Persetujuan

```markdown
## Lembar Persetujuan Narasumber

Judul penelitian : [judul]
Peneliti         : [nama], [NIM], Program Studi Informatika UAI
Pembimbing       : [nama]

Yang perlu Bapak/Ibu ketahui:
- Penelitian ini merupakan [tugas mata kuliah / tugas akhir]
- Wawancara berlangsung sekitar __ menit
- Nama Bapak/Ibu tidak akan ditulis lengkap; hanya inisial
- Bapak/Ibu dapat berhenti kapan saja tanpa alasan
- Bapak/Ibu dapat menarik keterangan sampai [tanggal]
- Rekaman [dilakukan/tidak], hanya dengan izin
- Data disimpan sampai [tanggal] lalu dihapus

Saya bersedia diwawancarai:
Nama (inisial) : ____    Tanggal : ____    Tanda tangan : ____

Kontak peneliti: [surel institusi]
```

## Lampiran B — Daftar Periksa

### B.1 Sebelum Berangkat Wawancara

| # | Butir | ☐ |
|---|-------|---|
| 1 | Panduan diperiksa tidak memimpin | ☐ |
| 2 | Pertanyaan tentang peristiwa, bukan pendapat | ☐ |
| 3 | Pertanyaan lanjutan tertulis | ☐ |
| 4 | Penandaan konstruk per bagian | ☐ |
| 5 | Lembar persetujuan siap | ☐ |
| 6 | Alat catat siap; izin rekaman akan diminta | ☐ |
| 7 | Pertanyaan penutup "siapa lagi yang sebaiknya saya temui" | ☐ |

### B.2 Verifikasi Sitasi

| # | Butir | ☐ |
|---|-------|---|
| 1 | DOI atau tautan permanen tersedia | ☐ |
| 2 | DOI dibuka | ☐ |
| 3 | Penulis cocok | ☐ |
| 4 | Tahun cocok | ☐ |
| 5 | Judul cocok | ☐ |
| 6 | Tempat terbit cocok | ☐ |
| 7 | **Naskah dibuka dan dibaca** (minimal abstrak, metode, simpulan) | ☐ |
| 8 | Status pracetak dinyatakan bila berlaku | ☐ |

### B.3 Sebelum Pengumpulan Data

| # | Butir | ☐ |
|---|-------|---|
| 1 | Instrumen diuji coba pada 3–5 orang dari populasi sasaran | ☐ |
| 2 | Protokol diuji: teman dapat menjalankannya tanpa bertanya | ☐ |
| 3 | Izin lembaga diperoleh (bila perlu) | ☐ |
| 4 | Lembar persetujuan siap | ☐ |
| 5 | **Rencana analisis ditulis dan diberi tanggal** | ☐ |
| 6 | Kriteria penolakan dugaan tertulis | ☐ |
| 7 | Tabel ancaman validitas disusun; ancaman berkemungkinan tinggi ditangani | ☐ |
| 8 | Kriteria evaluasi ditetapkan (untuk penelitian perancangan) | ☐ |
| 9 | Tempat penyimpanan data disiapkan | ☐ |

### B.4 Sebelum Menyerahkan Proposal

| # | Butir | ☐ |
|---|-------|---|
| 1 | Bab 1–3 lengkap dengan seluruh subbagiannya | ☐ |
| 2 | Lampiran A–F ada | ☐ |
| 3 | Deklarasi AI di bagian depan | ☐ |
| 4 | **Seluruh sitasi dibuka ulang satu per satu** | ☐ |
| 5 | Kontribusi dinyatakan sebagai pengetahuan | ☐ |
| 6 | *State of the art* disusun per tema | ☐ |
| 7 | Dua alternatif rancangan yang ditolak dijelaskan | ☐ |
| 8 | Jumlah subjek disertai perhitungan atau alasan | ☐ |
| 9 | Setiap kriteria evaluasi menunjuk kode kendala | ☐ |
| 10 | Ancaman validitas spesifik, ≥8 baris, dengan sisa risiko | ☐ |
| 11 | Angka konsisten antarbagian | ☐ |
| 12 | RQ di 1.3 sama persis dengan yang dirujuk di Bab 3 | ☐ |
| 13 | Jadwal muat dalam waktu tersedia | ☐ |

### B.5 Sebelum Seminar

| # | Butir | ☐ |
|---|-------|---|
| 1 | Proposal diserahkan H-3 | ☐ |
| 2 | Salindia ≤15 halaman | ☐ |
| 3 | Angka di salindia konsisten dengan naskah | ☐ |
| 4 | Latihan berwaktu ≥3 kali | ☐ |
| 5 | Jawaban untuk 10 pertanyaan disiapkan | ☐ |
| 6 | Pertanyaan untuk 2 proposal yang disanggah disiapkan | ☐ |
| 7 | Paket reproduksi dapat diakses penguji | ☐ |
| 8 | Cadangan berkas luring tersedia | ☐ |

|-----------|---------|---------|
| Pengelola pustaka | **Zotero** | Gratis; dianjurkan sejak Minggu 1 |
| | Mendeley, JabRef | Alternatif |

| | Spreadsheet | Memadai untuk skala Tugas Akhir |

> ditambahkan — yang memudahkan verifikasi DOI dan mencegah sitasi yang
> unsurnya tidak cocok.

## Lampiran E — Glosarium

| Istilah | Padanan | Arti dalam buku ini |
|---------|---------|---------------------|
| **Amanah** | Arab | Melaporkan apa yang benar-benar terjadi |
| **Ambang** | *threshold* | Batas yang menentukan kriteria terpenuhi atau tidak |
| **Analisis tematik** | *thematic analysis* | Analisis kualitatif enam tahap |
| **Artefak** | *artifact* | Yang dibangun dalam penelitian perancangan |
| **Besar efek** | *effect size* | Seberapa besar perbedaan, bukan seberapa mungkin |
| **Buku penanda** | *codebook* | Definisi setiap penanda beserta contohnya |
| **Deklarasi AI** | — | Pernyataan pemakaian AI per tahap, dengan verifikasinya |
| **Design science** | penelitian perancangan | Membangun artefak untuk menjawab pertanyaan |
| **Instansiasi** | *instantiation* | Artefak berupa sistem atau prototipe |
| **Kesenjangan** | *research gap* | Apa yang belum diketahui |
| **Kriteria penolakan** | — | Apa yang akan menjadi bukti dugaan tidak didukung |
| **Pemeriksaan anggota** | *member checking* | Menunjukkan tafsiran kepada responden |
| **Penjelasan tandingan** | *rival explanation* | Penjelasan lain atas pola data yang sama |
| **Pracetak** | *preprint* | Naskah yang belum ditelaah sejawat |
| **Praregistrasi** | *preregistration* | Menetapkan rencana analisis sebelum data |
| **PRISMA** | — | Pedoman pelaporan tinjauan sistematis |
| **Reliabilitas** | *reliability* | Konsistensi pengukuran |
| **Replicable** | dapat direplikasi | Orang lain, data baru, simpulan sama |
| **Reproducible** | dapat direproduksi | Orang lain, data sama, hasil sama |
| **RQ** | *research question* | Pertanyaan penelitian |
| **Saturasi** | *saturation* | Keadaan ketika tidak muncul tema baru |
| **Sisa risiko** | *residual risk* | Yang tetap mengancam setelah penanganan |
| **State of the art** | — | Keadaan pengetahuan terkini pada suatu topik |
| **Stakeholder** | pemangku kepentingan | Pihak yang terdampak atau berpengaruh |
| **Tertelusur** | *traceable* | Setiap klaim dapat ditunjuk sumbernya |
| **Triangulasi** | *triangulation* | Memeriksa temuan dari beberapa sumber |
| **Validitas konstruk** | — | Apakah yang diukur adalah yang dimaksud |
| **Validitas eksternal** | — | Sejauh mana berlaku di luar penelitian ini |
| **Validitas internal** | — | Apakah A benar-benar menyebabkan B |
| **Validitas simpulan** | — | Apakah simpulan didukung data |
