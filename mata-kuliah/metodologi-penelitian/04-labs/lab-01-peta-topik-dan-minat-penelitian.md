## Tujuan Lokakarya

Setelah lokakarya ini, mahasiswa memiliki tiga kandidat topik yang telah
dinilai dengan kriteria yang sama, dan satu topik terpilih beserta alasannya.

---

## Persiapan

| # | Yang disiapkan |
|---|----------------|
| 1 | Catatan dari bacaan pra-kelas: tiga hal yang pernah membuat Anda bertanya "kenapa begitu?" |
| 2 | Pengelola pustaka terpasang (Zotero atau sejenisnya) |
| 3 | Akses ke basis data kampus sudah diuji |

## Langkah-Langkah

### Langkah 1 — Menuliskan Kandidat (8 menit)

Tulis **tiga** kandidat topik. Untuk masing-masing, jawab dalam satu kalimat:

```markdown
### Kandidat A: [nama wilayah topik]
Apa yang membuat saya bertanya  :
Siapa yang terdampak persoalannya:
Apa yang sudah saya ketahui      :
Dari mana saya tahu itu          :
```

> Kandidat yang tidak dapat mengisi baris keempat menandakan pengetahuan yang
> berasal dari kesan, bukan dari sesuatu yang dibaca atau diamati. Itu belum
> tentu masalah pada tahap ini, tetapi harus disadari.

### Langkah 2 — Menilai dengan Kriteria yang Sama (10 menit)

Isi tabel berikut. Beri nilai 1 (rendah) sampai 3 (tinggi) untuk setiap
kriteria.

| Kriteria | Kandidat A | Kandidat B | Kandidat C |
|----------|-----------|-----------|-----------|
| Ketertarikan yang akan bertahan 6 bulan | | | |
| Kemungkinan ada kesenjangan | | | |
| **Akses ke data atau subjek** | | | |
| Bekal dari mata kuliah yang sudah ditempuh | | | |
| Ketersediaan pembimbing di prodi | | | |
| **Jumlah** | | | |

Untuk kriteria "akses", jawab secara konkret:

```markdown
Data/subjek yang diperlukan :
Siapa yang memilikinya       :
Sudahkah dihubungi?          :
Bila belum: kapan akan dihubungi?
```

> Kriteria "akses" adalah penyaring terkuat. Topik dengan nilai 1 pada baris
> itu hampir selalu gugur pada Minggu 10, ketika data harus mulai
> dikumpulkan.

### Langkah 3 — Uji Penyempitan (7 menit)

Ambil kandidat dengan jumlah tertinggi. Persempit tiga kali:

```
Tingkat 1 (terlalu luas) : Penerapan AI di pendidikan
Tingkat 2               : Pemakaian bantuan AI oleh dosen
                          dalam penilaian tugas
Tingkat 3               : Alasan dosen berhenti memakai fitur
                          penilaian otomatis pada sistem
                          akademik kampus
```

| Ujian tingkat 3 | Jawaban |
|-----------------|---------|
| Dapatkah disebut siapa yang akan ditanya? | |
| Dapatkah disebut apa yang akan diamati atau diukur? | |
| Dapatkah dikerjakan dalam 14 minggu? | |

Bila ada jawaban "tidak", persempit sekali lagi.

### Langkah 4 — Syarat Meninggalkan (5 menit)

Tulis satu paragraf:

```markdown
Saya akan meninggalkan topik ini bila:
1. [keadaan yang dapat diperiksa]
2. [keadaan yang dapat diperiksa]

Saya akan mengetahuinya pada Minggu ___, dari ___.
```

> Ini adalah butir yang paling sering ditanya mahasiswa alasannya. Jawabannya:
> topik yang tidak dapat dibayangkan ditinggalkan biasanya adalah topik yang
> sudah diputuskan lebih dahulu dan sedang dicarikan pembenarannya. Menuliskan
> syarat meninggalkan sejak awal menjaga agar bukti tetap dapat mengubah arah.

## Tantangan Tambahan

| # | Tantangan |
|---|-----------|
| 1 | Cari 3 judul Tugas Akhir angkatan sebelumnya pada wilayah topik Anda. Untuk masing-masing, tuliskan: pengetahuan apa yang dihasilkannya? Bila sulit dijawab, apa yang kurang? |
| 2 | Hubungi satu orang yang terdampak persoalan topik Anda. Tanyakan satu hal: "Bagian mana dari ini yang paling merepotkan?" Catat jawabannya verbatim. |
| 3 | Cari satu makalah terbaru pada wilayah topik Anda, buka bagian *Future Work*-nya, dan catat apa yang penulisnya sarankan untuk diteliti berikutnya. |

Tantangan 3 sering langsung menghasilkan kandidat kesenjangan untuk Minggu 2.
