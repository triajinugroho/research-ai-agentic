## Langkah-Langkah

### Langkah 1 — Fenomena dan Buktinya (7 menit)

```markdown
## Fenomena
[Satu paragraf: apa yang teramati]

## Bukti bahwa fenomena ini nyata
| Bukti | Sumber | Jenis |
|-------|--------|-------|
| | | data resmi / laporan / pengamatan sendiri / wawancara |
| | | |
```

| Ujian | Bila gagal |
|-------|------------|
| Setiap kalimat dalam paragraf fenomena punya bukti di tabel | Hapus kalimat itu atau cari buktinya |
| Ada minimal satu bukti yang bukan kesan pribadi | Kumpulkan data atau cari sumber |

> Kalimat seperti "banyak orang mengeluhkan…" tanpa sumber adalah kesan.
> Kesan boleh menjadi titik awal, tetapi tidak boleh masuk ke dokumen sebagai
> pernyataan fakta.

### Langkah 2 — Apa yang Sudah Diketahui (8 menit)

Isi tabel dari 5 sumber yang sudah Anda baca:

| # | Sitasi (penulis, tahun) | DOI | Apa yang sudah ditunjukkan | Konteks/populasinya |
|---|------------------------|-----|---------------------------|---------------------|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

Kolom terakhir adalah yang paling sering menghasilkan kesenjangan. Bila
kelima sumber meneliti konteks yang sama dan konteks Anda berbeda, kesenjangan
populasi sudah terlihat.

### Langkah 3 — Menentukan Jenis Kesenjangan (5 menit)

| Jenis | Berlaku? | Bukti dari tabel Langkah 2 |
|-------|----------|---------------------------|
| Kesenjangan bukti | | |
| Kesenjangan pengetahuan | | |
| Kesenjangan populasi | | |
| Kesenjangan metodologis | | |
| Kesenjangan praktik–teori | | |
| Pertentangan temuan | | |

Pilih **satu** yang paling kuat. Bila lebih dari satu berlaku, pilih yang
buktinya paling jelas.

### Langkah 4 — Merumuskan Pernyataan Kesenjangan (5 menit)

```
Penelitian terdahulu telah menunjukkan [APA YANG SUDAH DIKETAHUI]
pada [KONTEKS/POPULASI] [sitasi].

Namun [APA YANG BELUM DIKETAHUI],
khususnya pada [KONTEKS YANG BERBEDA].

Ketidaktahuan ini penting karena [AKIBAT PRAKTISNYA].
```

| Ujian | Bila gagal |
|-------|------------|
| Setiap frasa bersumber pada baris tabel Langkah 2 | Ganti dengan yang ada buktinya |
| Kalimat kedua tidak memakai frasa "belum ada yang meneliti" | Ganti dengan bentuk yang dapat diperiksa |
| Kalimat ketiga menyebut akibat yang nyata | Kesenjangan yang akibatnya tidak jelas sulit dipertahankan |

## Tinjauan Sebaya (15 menit)

Bertukar dokumen dengan satu teman. Isi lembar berikut:

```markdown
## Tinjauan Sebaya — Analisis Kesenjangan
Penulis : [nama]     Peninjau : [nama]     Tanggal :

1. Kalimat mana dalam paragraf fenomena yang TIDAK saya temukan
   buktinya di tabel?

2. Adakah sitasi yang DOI-nya tidak dapat saya buka?
   (Coba buka minimal 2 secara acak.)

3. Apakah kalimat "namun..." benar-benar mengikuti dari tabel
   "apa yang sudah diketahui"? Bila tidak, di mana lompatannya?

4. Apakah jenis kesenjangan yang dipilih sesuai dengan bukti
   yang disajikan?

5. Satu hal yang menurut saya paling kuat:

Catatan: peninjau TIDAK memperbaiki naskah. Peninjau menunjukkan
masalah; penulis yang memutuskan perbaikannya.
```

Butir 2 bersifat wajib dan sering menghasilkan temuan.

## Tantangan Tambahan

| # | Tantangan |
|---|-----------|
| 1 | Untuk setiap dari 5 sumber, buka bagian *Limitations* dan catat apa yang penulisnya akui belum terjawab. Adakah yang bertepatan dengan kesenjangan Anda? |
| 2 | Cari satu sumber yang **membantah** dugaan Anda. Bila tidak menemukannya setelah mencari sungguh-sungguh, catat bagaimana Anda mencarinya. |
| 3 | Tuliskan kesenjangan Anda dalam satu kalimat yang dapat dipahami orang di luar bidang Informatika. |

Tantangan 2 adalah kebiasaan yang paling melindungi dari kekeliruan. Mencari
bukti yang membantah dugaan sendiri jauh lebih jarang dilakukan daripada
mencari yang mendukung.

## AI Corner — Lokakarya 2

| Boleh | Tidak boleh |
|-------|-------------|
| Meminta AI menandai kalimat yang masih berupa masalah praktis | **Meminta AI menyebutkan kesenjangan pada topik Anda** |
| Meminta AI bertanya "apa buktinya?" atas tiap klaim Anda | Meminta AI menulis paragraf latar belakang |
| Meminta AI memeriksa kesesuaian jenis kesenjangan dengan bukti Anda | Meminta AI menambah sumber |

Kesenjangan yang disebut AI menggambarkan apa yang lazim ditulis orang, bukan
keadaan pustaka pada hari ini. Kesenjangan yang nyata hanya ditemukan dengan
membaca apa yang sudah ada.
