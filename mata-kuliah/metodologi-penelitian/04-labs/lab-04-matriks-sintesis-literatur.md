## Langkah-Langkah

### Langkah 1 — Mengisi Matriks (15 menit untuk 5 baris; sisanya mandiri)

| # | Sitasi | DOI | Masalah yang diangkat | Metode | Data/subjek | Temuan utama | **Keterbatasan yang diakui penulis** | Relevansi |
|---|--------|-----|----------------------|--------|-------------|--------------|--------------------------------------|-----------|
| 1 | | | | | | | | |
| 2 | | | | | | | | |

Ketentuan pengisian:

| Kolom | Ketentuan |
|-------|-----------|
| DOI | Harus sudah dibuka; tulis lengkap |
| Masalah | Satu kalimat, dengan kata-kata Anda sendiri |
| Metode | Sebutkan rancangannya, bukan hanya "kuantitatif" |
| Data/subjek | **Angka**: berapa orang, berapa berkas, dari mana |
| Temuan utama | Satu–dua kalimat; hati-hati membedakan temuan dari klaim |
| Keterbatasan | **Kutip dari bagian *Limitations*** naskahnya |
| Relevansi | Bagaimana ini berhubungan dengan penelitian Anda |

> Kolom "Keterbatasan" adalah yang paling sering dikosongkan dan paling
> berguna. Penulis yang jujur menuliskan sendiri apa yang belum dijawab
> penelitiannya. Bila sebuah makalah tidak memiliki bagian keterbatasan sama
> sekali, catat itu — ia sendiri merupakan penilaian atas mutu makalah.

### Langkah 2 — Mengelompokkan Menjadi Tema (8 menit)

```
1. Urutkan matriks menurut kolom "Masalah yang diangkat"
2. Tandai baris yang mengangkat masalah serupa
3. Dalam tiap kelompok, bandingkan kolom Metode dan Temuan
4. Beri nama kelompok itu
```

| Tema | Baris | Apa yang disepakati | Apa yang bertentangan | Apa yang belum disentuh |
|------|-------|---------------------|----------------------|-------------------------|
| | | | | |
| | | | | |
| | | | | |

Kolom keempat dan kelima adalah tempat kesenjangan berada.

### Langkah 3 — Menyusun Tabel Perbandingan (7 menit)

Untuk topik yang membandingkan pendekatan:

| Pendekatan | Sumber | Aspek 1 | Aspek 2 | Aspek 3 | Diuji pada |
|------------|--------|---------|---------|---------|------------|
| | | | | | |
| | | | | | |
| **[konteks Anda]** | **?** | | | | |

Baris terakhir yang kosong atau hanya berisi satu sumber adalah cara
menunjukkan kesenjangan tanpa menyatakannya.

### Langkah 4 — Menulis Narasi Tematik (mandiri)

Tulis 3–5 halaman **per tema**, bukan per sumber. Bentuk kalimat yang
dipakai:

| Jenis | Bentuk |
|-------|--------|
| Kesepakatan | "Enam penelitian [A–F] sepakat bahwa… meskipun dengan metode yang berbeda." |
| Pertentangan | "Tiga penelitian menemukan efek [A, C, E], dua tidak [B, D]. Perbedaannya terletak pada…" |
| Pola metodologis | "Seluruh penelitian pada tema ini memakai [metode]; tidak ada yang memakai [metode lain]." |
| Kekosongan | "Seluruh penelitian dilakukan pada [konteks X]; [konteks Y] belum disentuh." |

| Ujian narasi | Bila gagal |
|--------------|------------|
| Adakah paragraf yang hanya membahas satu sumber? | Gabungkan dengan sumber lain pada tema yang sama |
| Adakah kalimat yang menyebut ≥2 sumber? | Bila tidak ada sama sekali, ini masih ringkasan |
| Apakah pertentangan dibahas, bukan hanya disebut? | Jelaskan kemungkinan sebabnya |
| Apakah pembaca dapat melihat kesenjangan tanpa diberi tahu? | Perkuat tabel perbandingan |

## Tinjauan Sebaya (20 menit)

```markdown
## Tinjauan Sebaya — Matriks Sintesis
Penulis : [nama]     Peninjau : [nama]     Tanggal :

1. Pilih 3 baris secara acak. Buka DOI-nya. Apakah ketiganya ada?
   Baris ___ : ada / tidak
   Baris ___ : ada / tidak
   Baris ___ : ada / tidak

2. Berapa baris yang kolom "Keterbatasan" kosong? ___ dari ___

3. Adakah paragraf dalam narasi yang hanya membahas satu sumber?
   Sebutkan paragraf mana.

4. Apakah saya dapat melihat kesenjangannya tanpa diberi tahu?
   Bila tidak, apa yang kurang?

5. Satu hal yang menurut saya paling kuat:
```

Butir 1 bersifat wajib dan merupakan penerapan ketentuan verifikasi.

## Tantangan Tambahan

| # | Tantangan |
|---|-----------|
| 1 | Cari dua makalah yang temuannya bertentangan. Baca bagian metodenya dan rumuskan hipotesis tentang **mengapa** hasilnya berbeda. |
| 2 | Kumpulkan seluruh kolom "Keterbatasan" menjadi satu daftar. Kelompokkan. Adakah keterbatasan yang muncul pada banyak makalah? Itu kandidat kesenjangan yang kuat. |
| 3 | Untuk tema dengan sumber terbanyak, buat tabel perbandingan dengan minimal 5 aspek. Tandai sel yang kosong pada banyak baris — informasi yang tidak dilaporkan siapa pun adalah temuan tentang keadaan pustaka. |

laporkan berapa yang ternyata tidak ada. Angka itu menaikkan kepercayaan
terhadap yang tersisa.

## AI Corner — Lokakarya 4

| Boleh | Tidak boleh |
|-------|-------------|
| Meminta AI meringkas makalah **yang sudah Anda miliki dan baca** | Meringkas yang belum dibaca |
| Meminta AI mengusulkan nama tema dari matriks yang sudah terisi | Mengisi matriks |
| Meminta AI menandai baris yang temuannya tampak bertentangan | Menerima tanpa memeriksa ke naskah |
| Meminta AI memeriksa apakah narasi masih berupa ringkasan | Menulis narasi |

Yang hilang dari ringkasan otomatis: ukuran sampel, asumsi yang dinyatakan
penulis, bagian keterbatasan, dan **nada keraguan**. Penulis yang menulis
"hasil ini mengindikasikan kemungkinan hubungan" sering diringkas menjadi
"penelitian ini menemukan bahwa A memengaruhi B" — dan perbedaan itu
menentukan apakah Anda boleh membangun argumen di atasnya.
