# Studio 03: Persona dan Peta Perjalanan

| Aspek | Keterangan |
|-------|------------|
| Minggu | 3 · Sub-CPMK `091-1` · Bobot 3,3% (Observasi) |
| Durasi | 50' di kelas + 60' mandiri |
| Luaran | 1–2 persona + rumusan JTBD + peta perjalanan + analisis konteks |

---

## Tujuan Studio

1. Menyintesis kutipan wawancara menjadi tema tanpa kategori yang ditentukan lebih dahulu.
2. Menyusun persona yang **setiap pernyataannya terlacak** ke kutipan.
3. Merumuskan *jobs-to-be-done* tanpa menyebut solusi.
4. Memetakan perjalanan pengguna beserta titik nyerinya.

---

## Langkah-langkah

### LANGKAH 1: Sintesis dengan Kartu (di kelas, 50 menit)

**Persiapan:** tuliskan **setiap kutipan** dari seluruh wawancara pada kartu terpisah (atau baris terpisah di spreadsheet), dengan kode wawancara di sudutnya.

```
  ┌─────────────────────────────┐
  │ "Kalau jam makan siang itu  │
  │  ramai banget, sampai nggak │
  │  sempat nulis apa-apa."     │
  │                        [W03]│
  └─────────────────────────────┘
```

**Prosedur:**

| Tahap | Kegiatan | Waktu |
|-------|----------|-------|
| 1 | Sebar seluruh kartu di meja; baca semuanya tanpa mengelompokkan | 10' |
| 2 | Kelompokkan yang terasa serupa — **tanpa nama kelompok lebih dahulu** | 15' |
| 3 | Beri nama tiap kelompok; nama berasal dari isi kartu | 10' |
| 4 | Hitung: berapa narasumber berbeda menyumbang ke tiap kelompok | 5' |
| 5 | Urutkan kelompok berdasarkan jumlah narasumber | 5' |
| 6 | Tandai kelompok yang **bertentangan dengan dugaan awal** | 5' |

> **Aturan tahap 2:** jangan menyiapkan kategori sebelum membaca. Kategori yang ditentukan lebih dahulu akan memaksa kartu masuk ke dalamnya, dan tim akan "menemukan" apa yang sudah diduganya.

### LANGKAH 2: Menyusun Persona

```markdown
# Persona 1: [Nama panggilan deskriptif]

## Identitas Ringkas
[Peran], [konteks], [berapa lama]        [W03, W05, W09]

## Tujuan (apa yang ingin dicapai)
- [Tujuan 1]                             [W03, W09]
- [Tujuan 2]                             [W05]

## Hambatan
- [Hambatan 1]                           [W03, W05, W09]
- [Hambatan 2]                           [W07]

## Yang Sudah Dicoba
| Yang dicoba | Mengapa ditinggalkan | Bukti |
|-------------|---------------------|-------|
|             |                     |       |

## Kendala
| Jenis | Kendala | Bukti |
|-------|---------|-------|
| Waktu | | |
| Biaya | | |
| Perangkat | | |
| Keterampilan | | |

## Kutipan Penanda
> "[Satu kalimat verbatim yang paling mewakili persona ini]"  — [W0X]
```

**Aturan:**

- [ ] Setiap pernyataan memiliki **kode wawancara**
- [ ] Pernyataan tanpa kode **dihapus**, bukan ditandai
- [ ] Nama panggilan bersifat **deskriptif**, bukan nama orang karangan
- [ ] Maksimal 2 persona — lebih dari itu berarti segmen terlalu luas

### LANGKAH 3: Merumuskan *Jobs-to-be-Done*

Format: **Ketika** [situasi], **saya ingin** [motivasi], **sehingga saya dapat** [hasil].

| Lapis | Rumusan | Bukti |
|-------|---------|-------|
| **Fungsional** | Ketika ..., saya ingin ..., sehingga saya dapat ... | |
| **Emosional** | Ketika ..., saya ingin merasa ..., sehingga ... | |
| **Sosial** | Ketika ..., saya ingin dipandang ..., sehingga ... | |

**Periksa:**

- [ ] **Tidak ada kata "aplikasi", "sistem", atau nama produk**
- [ ] Situasi konkret, bukan umum
- [ ] Hasil yang diinginkan dapat diamati
- [ ] Ketiga lapis terisi

### LANGKAH 4: Peta Perjalanan

| Tahap → | | | | | |
|---------|---|---|---|---|---|
| **Nama tahap** | | | | | |
| **Apa yang dilakukan** | | | | | |
| **Apa yang dirasakan** | | | | | |
| **Titik nyeri** | | | | | |
| **Bukti** | | | | | |

**Menentukan titik nyeri terbesar:**

| Titik nyeri | Frekuensi disebut | Intensitas bahasa | Biaya disebut | Sudah diupayakan? | Skor |
|-------------|-------------------|-------------------|---------------|-------------------|------|
| | /15 | rendah/sedang/tinggi | | ya/tidak | |

> Titik nyeri yang layak diserang: **tinggi pada keempat kolom**. Masalah yang sering disebut tetapi tidak pernah diupayakan penyelesaiannya biasanya tidak cukup terasa untuk membuat orang membayar.

### LANGKAH 5: Analisis Konteks Penggunaan

| Dimensi | Temuan | Bukti | Implikasi bagi solusi |
|---------|--------|-------|----------------------|
| **Fisik** | Di mana? Posisi tubuh? Tangan bebas? | | |
| **Waktu** | Kapan? Berapa lama tersedia? | | |
| **Perangkat** | Ponsel apa? Layar? Koneksi? | | |
| **Sosial** | Sendirian atau di depan orang? | | |
| **Kemampuan** | Literasi digital? Penglihatan? | | |
| **Kendala** | Biaya data? Listrik? | | |

> Kolom terakhir adalah yang paling berguna: ia menerjemahkan konteks menjadi batasan rancangan. **Konteks penggunaan mengalahkan fitur.**

## Tantangan Tambahan

### Tantangan 1 — Persona Negatif

Susun satu "persona negatif": siapa yang **bukan** pengguna kita, dan mengapa. Ini mempertajam batas segmen dan mencegah tim melebarkan sasaran.

### Tantangan 2 — Menguji Persona ke Narasumber

Tunjukkan persona kepada dua narasumber yang pernah diwawancarai. Tanyakan: *"apakah ini menggambarkan Anda? Bagian mana yang tidak tepat?"* Catat jawabannya.

### Tantangan 3 — Mencari Kontradiksi

Temukan dua kutipan dari narasumber berbeda yang **saling bertentangan**. Apa yang menjelaskan perbedaan itu? Sering ini menandakan adanya dua segmen yang berbeda.

---

## Checklist Penyelesaian

- [ ] Seluruh kutipan dituliskan pada kartu/baris terpisah dengan kode
- [ ] Pengelompokan dilakukan **tanpa kategori yang ditentukan lebih dahulu**
- [ ] 1–2 persona disusun dengan **keterlacakan penuh**
- [ ] Tidak ada pernyataan persona tanpa kode wawancara
- [ ] JTBD dirumuskan pada tiga lapis, **tanpa menyebut solusi**
- [ ] Peta perjalanan memuat **baris bukti**
- [ ] Titik nyeri terbesar ditentukan dengan tabel skor
- [ ] Analisis konteks enam dimensi diisi dengan kolom implikasi
- [ ] Kelompok yang **bertentangan dengan dugaan awal** ditandai
- [ ] AI Usage Log disertakan
