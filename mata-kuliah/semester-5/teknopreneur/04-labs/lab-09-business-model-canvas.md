## Tujuan Studio

1. Menyusun *value proposition canvas* dari bukti pelanggan.
2. Mengisi BMC dengan keterlacakan ke dokumen asal.
3. Menguji konsistensi antarkotak.
4. Memilih pola model bisnis beserta pertimbangan etisnya.

### LANGKAH 2: *Value Proposition Canvas* — Sisi Produk

| Unsur | Isi | Menjawab *pain*/*gain* mana |
|-------|-----|----------------------------|
| Produk dan layanan | | |
| *Pain relievers* | | |
| *Gain creators* | | |

**Uji kecocokan:**

| Pemeriksaan | Temuan |
|-------------|--------|
| Apakah *pain* terbesar sudah dijawab? | |
| Adakah *pain reliever* **tanpa *pain* pasangan**? | |
| Adakah *pain* besar yang **tidak dijawab**? | |

> ***Pain reliever* tanpa pasangan adalah fitur yang diinginkan tim, bukan pelanggan.** Hapus atau turunkan prioritasnya.

### LANGKAH 3: Mengisi BMC

Ikuti urutan dari bukti:

```
  1. Segmen Pelanggan   → dari persona (S-03)
  2. Proposisi Nilai    → dari VPC (langkah 1-2)
  3. Saluran            → dari kutipan: "cari di mana?"
  4. Hubungan Pelanggan → dari analisis konteks (S-03)
  5. Arus Pendapatan    → dari penetapan harga (S-07)
  6. Sumber Daya Kunci  → dari kelayakan teknis (S-06)
  7. Kegiatan Kunci     → dari kelayakan teknis (S-06)
  8. Mitra Kunci        → dari keputusan build/buy (S-06)
  9. Struktur Biaya     → dari unit economics (S-07)
```

**Format pengisian:**

| # | Kotak | Isi | **Sumber/bukti** |
|---|-------|-----|------------------|
| 1 | Segmen Pelanggan | | S-03, W03/W05/W09 |
| 2 | Proposisi Nilai | | VPC |
| 3 | Saluran | | W02/W07 |
| 4 | Hubungan Pelanggan | | S-03 konteks |
| 5 | Arus Pendapatan | | S-07 |
| 6 | Sumber Daya Kunci | | S-06 |
| 7 | Kegiatan Kunci | | S-06 |
| 8 | Mitra Kunci | | S-06 |
| 9 | Struktur Biaya | | S-07 |

> **Kotak tanpa kolom sumber yang terisi akan ditandai.** BMC yang diisi dari dugaan tidak lebih bernilai daripada tidak mengisinya.

### LANGKAH 4: Uji Konsistensi

| Pasangan | Pemeriksaan | Sesuai? | Catatan |
|----------|-------------|---------|---------|
| Segmen ↔ Saluran | Apakah segmen ini benar-benar ada di saluran itu? | | |
| Proposisi ↔ Struktur Biaya | Apakah biaya mencerminkan yang dijanjikan? | | |
| Hubungan ↔ Biaya | Bila menjanjikan pendampingan, adakah biaya orang? | | |
| Arus Pendapatan ↔ Segmen | Apakah harga masuk akal bagi kemampuan segmen? | | |
| Kegiatan ↔ Sumber Daya | Apakah tim memiliki yang dibutuhkan? | | |
| Kegiatan ↔ Mitra | Apakah yang tidak dikuasai sudah diserahkan ke mitra? | | |

### LANGKAH 5: Uji Cerita (di kelas)

Bacakan BMC sebagai **satu paragraf**:

> "Kami melayani **[segmen]** yang mengalami **[masalah]**. Kami menyediakan **[proposisi nilai]**. Mereka menemukan kami melalui **[saluran]**, dan kami menjaga hubungan melalui **[hubungan]**. Mereka membayar **[arus pendapatan]**. Untuk itu kami membutuhkan **[sumber daya]** dan mengerjakan **[kegiatan]**, dibantu **[mitra]**. Biaya terbesar kami adalah **[struktur biaya]**."

**Catat bagian yang terasa janggal ketika dibaca** — itu menandakan ketidaksesuaian antarkotak.

## Tantangan Tambahan

### Tantangan 1 — BMC Alternatif

Susun BMC kedua dengan model bisnis yang berbeda untuk segmen yang sama. Bandingkan: mana yang lebih sesuai dengan bukti wawancara? Mana yang lebih mudah dijalankan tim?

### Tantangan 2 — Menguji Proposisi Nilai

Sampaikan proposisi nilai (satu kalimat) kepada tiga narasumber. Tanyakan: *"kalau Anda dengar ini, apa yang Anda bayangkan? Apakah menarik?"* Catat jawaban verbatim.

### Tantangan 3 — Menghitung Ulang dengan BMC

Setelah BMC selesai, periksa ulang model *unit economics* Studio 7. Adakah biaya yang muncul dari BMC yang belum masuk perhitungan? Biasanya ada — terutama pada kotak Hubungan Pelanggan.
