## Langkah-Langkah

### Langkah 1 — Menguraikan Menjadi Konsep (5 menit)

```markdown
Pertanyaan/kesenjangan saya:
[tulis]

Konsep A (inti persoalan)  :
Konsep B (objek/teknologi)  :
Konsep C (konteks/populasi) :
```

Tiga konsep biasanya cukup. Lebih dari empat konsep menghasilkan pencarian
yang terlalu sempit.

### Langkah 2 — Mengumpulkan Sinonim (8 menit)

| Konsep | Istilah utama | Sinonim dan variasi |
|--------|---------------|---------------------|
| A | | |
| B | | |
| C | | |

Cara menemukan sinonim:

| Cara | Penjelasan |
|------|------------|
| Baca kata kunci pada 3–5 makalah yang sudah dimiliki | Sumber terbaik |
| Periksa istilah yang dipakai judul dan abstraknya | Sering berbeda dari dugaan |
| Cari istilah Inggris dan Indonesia | Untuk basis data Garuda/SINTA |
| Perhatikan bentuk jamak dan variasi ejaan | *behavior/behaviour*, *organisation/organization* |

> Satu sinonim penting yang terlewat dapat menyembunyikan seluruh cabang
> pustaka. Luangkan waktu pada langkah ini.

### Langkah 3 — Menyusun Rumus Pencarian (7 menit)

```
(A1 OR A2 OR A3) AND (B1 OR B2) AND (C1 OR C2 OR C3)
```

Catat rumus **persis sebagaimana diketik** untuk setiap basis data:

| Basis data | Rumus persis | Tanggal | Jumlah hasil |
|------------|--------------|---------|--------------|
| ACM DL | | | |
| IEEE Xplore | | | |
| Scopus/ScienceDirect | | | |
| Garuda/SINTA | | | |
| Google Scholar | | | |

Sintaks berbeda antar basis data; catat apa adanya, jangan disamakan.

### Langkah 4 — Kriteria Inklusi dan Eksklusi (5 menit)

```markdown
## Kriteria Inklusi
- Terbit [tahun] – 2026
- Bahasa: Indonesia atau Inggris
- Jenis: artikel jurnal, prosiding konferensi telaah sejawat
- Membahas [konsep A] pada [konteks B]

## Kriteria Eksklusi
- Abstrak saja, tanpa naskah penuh
- Tidak membahas [konsep A] meskipun kata kuncinya muncul
- Naskah tidak dapat diakses
- Duplikat
```

Kriteria harus **dapat diterapkan orang lain dengan hasil yang sama**.
"Relevan dengan penelitian saya" bukan kriteria; ia keputusan.

### Langkah 5 — Menjalankan dan Mencatat (10 menit di kelas, dilanjutkan mandiri)

```
Identifikasi
  ACM DL          : ___
  IEEE Xplore     : ___
  Scopus          : ___
  Garuda/SINTA    : ___
  Google Scholar  : ___
  ───────────────────────
  Total           : ___
  Duplikat dibuang: ___
        ↓
Penyaringan (judul & abstrak)
  Diperiksa       : ___
  Dibuang         : ___  (alasan tersering: ___)
        ↓
Kelayakan (naskah penuh)
  Diperiksa       : ___
  Dibuang         : ___  (alasan: ___)
        ↓
Disertakan        : ___  (target ≥40 kandidat, ≥20 dibaca penuh)
```

Diagram ini adalah bentuk sederhana dari diagram alir PRISMA, dan menjadi
lampiran wajib T3.

---

## Tantangan Tambahan

| # | Tantangan |
|---|-----------|
| 1 | **Penelusuran bola salju.** Ambil 3 makalah paling relevan. Periksa daftar pustakanya (mundur) dan cari siapa yang menyitasinya (maju). Catat berapa sumber baru yang ditemukan dengan cara ini yang **tidak** muncul dalam pencarian kata kunci. |
| 2 | Jalankan rumus Anda pada basis data yang berbeda dan bandingkan jumlah hasilnya. Jelaskan mengapa berbeda. |
| 3 | Minta teman menjalankan protokol Anda persis seperti tertulis. Bandingkan jumlah hasilnya dengan hasil Anda. Bila berbeda jauh, cari bagian protokol yang tidak jelas. |

Tantangan 1 hampir selalu menghasilkan sumber penting yang terlewat.
Tantangan 3 adalah ujian yang sebenarnya untuk "dapat diulang".

### Latihan Wajib: Menemukan Sitasi yang Tidak Ada

Di kelas, dosen membagikan 5 sitasi. Sebagian tidak ada.

```markdown
| # | Sitasi | DOI dibuka? | Penulis cocok? | Judul cocok? | Ada? |
|---|--------|-------------|----------------|--------------|------|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

Berapa yang tidak ada: ___
Ciri apa yang membedakannya dari yang nyata: ___
```

Baris terakhir sering sulit dijawab — dan itulah pelajarannya. Sitasi yang
dikarang tidak memiliki ciri yang dapat dikenali dari bentuknya. Satu-satunya
cara memastikan adalah membukanya.
