## Langkah-Langkah

### Langkah 1 — Mendaftar Konstruk Kandidat (7 menit)

Telusuri matriks T4. Catat konsep yang muncul berulang:

| Konstruk kandidat | Muncul pada baris | Istilah yang dipakai penulis |
|-------------------|-------------------|------------------------------|
| | | |
| | | |
| | | |

> Kolom ketiga sering mengungkap bahwa beberapa makalah membicarakan hal yang
> sama dengan istilah berbeda. Menyatukannya adalah bagian dari sintesis.

### Langkah 2 — Menyusun Definisi Operasional (10 menit)

| Konstruk | Definisi konseptual | **Definisi operasional** | Sumber definisi |
|----------|--------------------|--------------------------|-----------------|
| | | | |
| | | | |
| | | | |

| Ujian | Bila gagal |
|-------|------------|
| Definisi operasional menyebut **bagaimana diukur atau diamati** | Konstruk tidak dapat dikumpulkan datanya |
| Sumber definisi menunjuk makalah tertentu | Bila disusun sendiri, tandai demikian |
| Instrumen tervalidasi dipakai bila tersedia | Lebih kuat daripada menyusun sendiri |

Contoh:

| Konstruk | Definisi konseptual | Definisi operasional |
|----------|--------------------|-----------------------|
| Penghentian pemakaian | Berhentinya pemakaian yang sebelumnya rutin | Tidak ada aktivitas tercatat ≥30 hari berturut-turut setelah periode aktif ≥14 hari |
| Keterjelasan sistem | Sejauh mana pengguna memahami apa yang dilakukan sistem | Skor 4 butir diadaptasi dari [sumber]; ditambah pertanyaan wawancara tentang penjelasan pengguna atas keluaran sistem |

### Langkah 3 — Menggambar Diagram (8 menit)

Gambar dengan tangan atau teks. Setiap kotak adalah konstruk; setiap panah
adalah hubungan dengan arah dugaannya.

```
  ┌─────────────┐           ┌─────────────┐
  │             │  H1: +    │             │
  │  [konstruk] │──────────►│  [konstruk] │
  └─────────────┘           └─────────────┘
         ▲
         │ H2: −
  ┌─────────────┐
  │  [konstruk] │
  └─────────────┘

  Variabel kendali: ____________
```

### Langkah 4 — Tabel Sumber (5 menit)

| Unsur | Jenis | Sumber |
|-------|-------|--------|
| Konstruk A | konstruk | [sitasi] |
| Konstruk B | konstruk | [sitasi] |
| A → B (positif) | hubungan | [sitasi] |
| C → B (negatif) | hubungan | [sitasi] |

| Ujian | Bila gagal |
|-------|------------|
| Setiap kotak ada di tabel | Konstruk tanpa sumber → cari atau tandai sebagai usulan sendiri |
| **Setiap panah ada di tabel** | Hubungan tanpa sumber adalah dugaan tanpa dasar |
| Sumber berasal dari matriks T4 | Sumber baru harus diverifikasi DOI |

### Langkah 5 — Variabel yang Tidak Dimasukkan

| Variabel | Mengapa tampak relevan | Mengapa tidak dimasukkan |
|----------|------------------------|--------------------------|
| | | |
| | | |

> Penguji hampir selalu menanyakan variabel yang tampak relevan tetapi tidak
> ada dalam kerangka. Menyiapkan jawaban ini sekarang menghemat kegugupan di
> Minggu 15.

### Langkah 6 — Proposisi atau Hipotesis

| Kode | Rumusan | Bentuk | Bagaimana diuji |
|------|---------|--------|-----------------|
| H1/P1 | | hipotesis / proposisi | |
| H2/P2 | | | |

Untuk penelitian *design science*, bagian ini sering diganti dengan kriteria
evaluasi (Lokakarya 13).

## Tantangan Tambahan

| # | Tantangan |
|---|-----------|
| 1 | Cari satu makalah dalam matriks T4 yang memakai kerangka konseptual eksplisit. Bandingkan dengan kerangka Anda: apa yang mereka masukkan yang Anda tidak, dan sebaliknya? |
| 2 | Untuk setiap hubungan dalam kerangka Anda, tulis satu kalimat: "Bila hubungan ini tidak ditemukan, artinya…". |

## AI Corner — Lokakarya 7

| Boleh | Tidak boleh |
|-------|-------------|
| Meminta AI menjelaskan teori yang Anda temukan dalam pustaka | Meminta AI memilih teori |
| Meminta AI memeriksa keterukuran definisi operasional | Menyusun definisi operasional |
| Meminta AI menandai panah yang belum bersumber | **Meminta AI menyebutkan sumber untuk sebuah hubungan** |
| Meminta AI mengajukan pertanyaan tentang variabel yang terlewat | Menambahkan variabel tanpa mencari sumbernya |

Setiap hubungan dalam kerangka harus bersumber pada makalah yang **Anda baca
sendiri** dalam matriks T4. Sitasi yang disebut AI untuk sebuah hubungan
adalah kandidat yang harus diverifikasi, bukan sumber.
