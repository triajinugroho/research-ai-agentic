## 2. Deskripsi Bahan Kajian

### BK01 — Artificial Intelligence

Mengkaji representasi, penalaran, pencarian, pembelajaran mesin, pengambilan keputusan, agen cerdas, bahasa, robotika, dan persepsi; sekaligus dampak sosial dan etika AI.

*Kode KA: `AI` · CS Core Hours: 12 · KA Core Hours: 18 · Referensi: CS2023*

<https://csed.acm.org/artificial-intelligence/>

### BK02 — Algorithmic Foundations

Fondasi desain dan analisis algoritma, struktur data, strategi algoritmik, kompleksitas, komputabilitas, bahasa formal, serta konsekuensi sosial penggunaan algoritma.

*Kode KA: `AL` · CS Core Hours: 32 · KA Core Hours: 32 · Referensi: CS2023*

<https://csed.acm.org/algorithms-and-complexity/>

### BK03 — Architecture and Organization

Mengkaji representasi data tingkat mesin, organisasi prosesor, memori, I/O, kinerja/energi, arsitektur heterogen, keamanan prosesor, quantum architecture, dan keberlanjutan.

*Kode KA: `AR` · CS Core Hours: 9 · KA Core Hours: 16 · Referensi: CS2023*

<https://csed.acm.org/architecture-and-organization/>

### BK04 — Data Management

Mengelola data sepanjang siklus hidupnya: pemodelan, basis data relasional/NoSQL, query, internals DBMS, analytics, keamanan/privacy, distributed/cloud, dan data tak terstruktur.

*Kode KA: `DM` · CS Core Hours: 10 · KA Core Hours: 26 · Referensi: CS2023*

<https://csed.acm.org/data-management/>

### BK05 — Foundations of Programming Languages

Mengkaji paradigma bahasa, sistem tipe, model eksekusi/memori, penerjemahan bahasa, compiler, analisis program, konstruksi lanjut, semantik formal, dan prinsip desain bahasa.

*Kode KA: `FPL` · CS Core Hours: 21 · KA Core Hours: 19 · Referensi: CS2023*

<https://csed.acm.org/programming-languages/>

### BK06 — Graphics and Interactive Techniques

Mengkaji grafika dan teknik interaktif: visualisasi, rendering, geometric modeling, shading, animasi, simulasi, immersion, interaction, image processing, dan physical computing.

*Kode KA: `GIT` · CS Core Hours: 4 · KA Core Hours: 70 · Referensi: CS2023*

<https://csed.acm.org/graphics-and-interactive-techniques/>

### BK07 — Human-Computer Interaction

Berfokus pada pengguna, desain berpusat manusia, akuntabilitas desain, aksesibilitas dan inklusi, evaluasi/usability, system design, serta implikasi etika dan sosial.

*Kode KA: `HCI` · CS Core Hours: 8 · KA Core Hours: 16 · Referensi: CS2023*

<https://csed.acm.org/human-computer-interaction/>

### BK08 — Mathematical and Statistical Foundations

Fondasi matematika modern untuk CS: matematika diskrit, probabilitas, statistika, aljabar linear, dan kalkulus—termasuk kebutuhan AI/ML, data science, graphics, security, dan quantum.

*Kode KA: `MSF` · CS Core Hours: 55 · KA Core Hours: 145 · Referensi: CS2023*

<https://csed.acm.org/mathematical-and-statistical-foundations/>

### BK09 — Networking and Communication

Mengkaji prinsip jaringan, aplikasi berjaringan, reliability, routing/forwarding, single-hop communication, mobility, network security, dan emerging networking topics.

*Kode KA: `NC` · CS Core Hours: 7 · KA Core Hours: 24 · Referensi: CS2023*

<https://csed.acm.org/networking-and-communication/>

### BK10 — Operating Systems

Mengkaji peran OS, prinsip kernel, concurrency, protection, scheduling, process, memory, devices, file systems, virtualization, real-time/embedded, fault tolerance, dan SEP.

*Kode KA: `OS` · CS Core Hours: 8 · KA Core Hours: 13 · Referensi: CS2023*

<https://csed.acm.org/operating-systems/>

### BK11 — Parallel and Distributed Computing

Mengkaji program paralel/distribusi, komunikasi, koordinasi, evaluasi kinerja/kebenaran, serta algoritma pada multicore, GPU, cluster, cloud, dan sistem terdistribusi.

*Kode KA: `PDC` · CS Core Hours: 9 · KA Core Hours: 26 · Referensi: CS2023*

<https://csed.acm.org/parallel-and-distributed-computing/>

### BK12 — Software Development Fundamentals

Fondasi pengembangan perangkat lunak: konsep dan praktik pemrograman, struktur data, algoritma, testing/debugging/readability/tooling dasar, serta tanggung jawab profesional.

*Kode KA: `SDF` · CS Core Hours: 43 · Referensi: CS2023*

<https://csed.acm.org/software-development-fundamentals/>

### BK13 — Software Engineering

Rekayasa perangkat lunak multi-person dan multi-version: teamwork, tools/workflow, requirements, design, construction, verification-validation, refactoring/evolution, reliability, dan formal methods.

*Kode KA: `SE` · CS Core Hours: 6 · KA Core Hours: 21 · Referensi: CS2023*

<https://csed.acm.org/software-engineering/>

### BK14 — Security

Membangun security mindset melalui foundational security, secure coding, cryptography, security engineering, digital forensics, governance, dan isu etika/profesional.

*Kode KA: `SEC` · CS Core Hours: 6 · KA Core Hours: 35 · Referensi: CS2023*

<https://csed.acm.org/security/>

### BK15 — Society, Ethics, and the Profession

Mengkaji konteks sosial, analisis etika, etika profesi, HKI, privacy/civil liberties, komunikasi, sustainability, sejarah computing, ekonomi computing, hukum/kejahatan komputer, dan DEIA.

*Kode KA: `SEP` · CS Core Hours: 18 · KA Core Hours: 14 · Referensi: CS2023*

<https://csed.acm.org/society-ethics-and-professionalism/>

### BK16 — Systems Fundamentals

Memberi pandangan sistem menyeluruh: overview sistem komputer, konsep dasar, resource management, performance, evaluation, reliability, security, system design, dan SEP.

*Kode KA: `SF` · CS Core Hours: 18 · KA Core Hours: 8 · Referensi: CS2023*

<https://csed.acm.org/knowledge-area-subcommittees/systems-fundamentals>

### BK17 — Specialized Platform Development

Pengembangan pada platform khusus: shared concerns, web, mobile, robot, embedded, game, interactive computing, serta isu SEP yang spesifik terhadap platform.

*Kode KA: `SPD` · CS Core Hours: 4 · Referensi: CS2023*

<https://csed.acm.org/specialized-platform-development/>

### BK18 — Pengembangan Diri

Bahan kajian yang mencakup pengembangan kompetensi personal dan interpersonal untuk mendukung keberhasilan akademik, profesional, dan sosial, meliputi kesadaran dan pengelolaan diri, komunikasi, kolaborasi, kepemimpinan, kemampuan beradaptasi, pemecahan masalah, etika dan tanggung jawab, kemandirian, serta pembelajaran sepanjang hayat.

*Kode KA: `–` · Referensi: APTIKOM2024*

### BK19 — Metodologi

Bahan kajian yang mencakup prinsip dan metode ilmiah untuk memperoleh, mengembangkan, dan mengomunikasikan pengetahuan secara sistematis, meliputi perumusan masalah, kajian literatur, penyusunan kerangka konseptual, perancangan metode penelitian atau pengembangan, pengumpulan dan analisis data, evaluasi hasil, penarikan kesimpulan, serta penyusunan dan komunikasi karya ilmiah secara etis.

*Kode KA: `–` · Referensi: APTIKOM2024*
